# 🚀 Production Azure MLOps & GenAI/RAG Platform

> A production-grade, end-to-end reference platform demonstrating how
> Machine Learning and GenAI workloads are built, deployed, monitored,
> secured, and operated on Microsoft Azure.

---

## 🎯 What is this project?

This project demonstrates an enterprise-style **MLOps + GenAI/RAG platform**
on Azure.

The goal is not to build a simple ML model or chatbot.

The goal is to understand what happens when an ML or GenAI workload needs
to operate like a real production system:

- Reliable data ingestion
- Data validation
- Data versioning
- Feature engineering
- Feature management
- Model training
- Experiment tracking
- Model registry
- Model evaluation
- Real-time inference
- Batch inference
- CI/CD
- Continuous testing
- Kubernetes deployment
- Monitoring
- Data and model drift detection
- Retraining
- Canary deployment
- Rollback
- Security
- Governance
- Disaster recovery
- RAG evaluation
- LLM observability
